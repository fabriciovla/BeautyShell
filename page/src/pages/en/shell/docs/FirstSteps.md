## The welcome tour

The first time you open Beauty Shell, a full-screen tour appears. Everything you choose applies on the spot, so you see how it looks before moving on:

1. **Theme**: light, dark or like Windows.
2. **Shell**: the one each new terminal opens (PowerShell 7, Windows PowerShell, cmd, Git Bash or WSL, depending on what you have).
3. **Font and cursor**: the terminal typeface and the cursor shape.
4. **Agents**: which coding agents it found on your computer.
5. **Keybindings**: the ones you'll use most to get started.

Everything can be changed later in **Settings** (<kbd>Ctrl+,</kbd>). The tour only shows once.

## Your first terminal

With no tabs open, Beauty Shell shows its start screen. To open a terminal:

- Press <kbd>Ctrl+T</kbd>.
- Or click **New terminal** in the sidebar.
- Or double-click the empty space below the tabs.

The new terminal opens **in the same folder as the current tab**. The first one starts in your user folder.

### Choose another shell or folder

**Right-clicking New terminal** shows a menu with:

- Each installed shell, to open that one instead of the default.
- **Open in folder…**, to pick where it starts.
- **Browser**, which opens a page instead of a terminal (see [Built-in browser](/en/shell/docs/browser/)).

## What you'll see

- **On the left, the sidebar**, with your terminals grouped by folder. It's explained in [Tabs and folders](/en/shell/docs/tabs/).
- **In the middle, the terminal.** You can split it into several panes: see [Split panes](/en/shell/docs/panes/).
- **On top, nothing.** The window has no title bar. When you move the mouse to the top edge, a strip with the Windows controls (minimize, maximize and close) appears. You can also drag the window from that strip, and double-click it to maximize.

## Three shortcuts to start with

| To | Shortcut |
| --- | --- |
| Open a terminal in the same folder | <kbd>Ctrl+T</kbd> |
| Find any action or terminal | <kbd>Ctrl+Shift+P</kbd> |
| Split the pane to the right | <kbd>Ctrl+Shift+D</kbd> |

The rest are in [Keybindings](/en/shell/docs/keybindings/).
