## 1. What Beauty Shell is

Beauty Shell is a desktop app for Windows that opens terminals (PowerShell, Windows PowerShell, cmd, Git Bash and WSL, depending on what you have installed), groups them by folder, splits them into panes and adds tools such as a built-in browser and a connection with coding agents. ## 4. What runs in your terminals is yours

The app opens your computer's shells with your Windows user's permissions. The commands you type, the programs you run and what those programs do are your responsibility, just like in any other terminal. Beauty Shell doesn't review or stop what you run.

Some features type into your terminals for you, always because you asked them to:

- **Workspaces**: when you open one, the app runs again the command saved for each pane (for example `npm run dev`).
- **Type in all panes**: what you type goes to every pane in the tab.
- **Installing agents** from Settings: the app runs, in a terminal, the install command published by each agent.

If you connect an agent to Beauty Shell (for example with **Connect Claude Code** in Settings), that agent will be able to see the list of your terminals, read what they show, type into them and open or read pages in the built-in browser. Connecting it is your decision, and what the agent does with that access is the responsibility of whoever uses it and whoever makes it. You can disconnect it at any time.
