## La bienvenida

La primera vez que abrís Beauty Shell aparece un recorrido a pantalla completa. Cada cosa que elegís se aplica en el momento, así que ves cómo queda antes de seguir:

1. **Tema**: claro, oscuro o como Windows.
2. **Shell**: la que se abre en cada terminal nueva (PowerShell 7, Windows PowerShell, cmd, Git Bash o WSL, según lo que tengas).
3. **Letra y cursor**: la tipografía de la terminal y la forma del cursor.
4. **Agentes**: qué agentes de código encontró en tu equipo.
5. **Atajos**: los que más vas a usar para empezar.

Todo se puede cambiar después en **Ajustes** (<kbd>Ctrl+,</kbd>). La bienvenida aparece una sola vez.

## Tu primera terminal

Sin pestañas abiertas, Beauty Shell muestra su pantalla de inicio. Para abrir una terminal:

- Presioná <kbd>Ctrl+T</kbd>.
- O hacé clic en **Nueva terminal**, en la barra lateral.
- O hacé doble clic en el espacio vacío debajo de las pestañas.

La terminal nueva se abre **en la misma carpeta que la pestaña actual**. La primera arranca en tu carpeta de usuario.

### Elegir otra shell u otra carpeta

Con **clic derecho en Nueva terminal** aparece un menú con:

- Cada shell instalada, para abrir esa en vez de la predeterminada.
- **Abrir en carpeta…**, que te deja elegir dónde arranca.
- **Navegador**, que abre una página en vez de una terminal (ver [Navegador integrado](/shell/docs/navegador/)).

## Lo que vas a ver

- **A la izquierda, la barra lateral**, con tus terminales agrupadas por carpeta. Se explica en [Pestañas y carpetas](/shell/docs/pestanas/).
- **En el centro, la terminal.** Podés dividirla en varios paneles: ver [Paneles divididos](/shell/docs/paneles/).
- **Arriba, nada.** La ventana no tiene barra de título. Al llevar el mouse al borde de arriba aparece una franja con los controles de Windows (minimizar, maximizar y cerrar). Desde esa franja también se arrastra la ventana, y con doble clic se maximiza.

## Tres atajos para empezar

| Para | Atajo |
| --- | --- |
| Abrir una terminal en la misma carpeta | <kbd>Ctrl+T</kbd> |
| Buscar cualquier acción o terminal | <kbd>Ctrl+Shift+P</kbd> |
| Dividir el panel a la derecha | <kbd>Ctrl+Shift+D</kbd> |

El resto está en [Atajos de teclado](/shell/docs/atajos/).
