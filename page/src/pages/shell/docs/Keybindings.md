## Pestañas

| Acción | Atajo |
| --- | --- |
| Nueva terminal en la misma carpeta | <kbd>Ctrl+T</kbd> |
| Cerrar pestaña | <kbd>Ctrl+Shift+W</kbd> |
| Reabrir lo último cerrado | <kbd>Ctrl+Shift+T</kbd> |
| Pestaña siguiente | <kbd>Ctrl+Tab</kbd> o <kbd>Ctrl+AvPág</kbd> |
| Pestaña anterior | <kbd>Ctrl+Shift+Tab</kbd> o <kbd>Ctrl+RePág</kbd> |
| Ir a la pestaña 1…8 | <kbd>Ctrl+1</kbd> … <kbd>Ctrl+8</kbd> |
| Ir a la última pestaña | <kbd>Ctrl+9</kbd> |

## Terminal

| Acción | Atajo |
| --- | --- |
| Buscar | <kbd>Ctrl+F</kbd> |
| Ir al comando anterior o siguiente (PowerShell) | <kbd>Ctrl+↑</kbd> / <kbd>Ctrl+↓</kbd> |
| Copiar la selección | <kbd>Ctrl+C</kbd> o <kbd>Ctrl+Shift+C</kbd> |

## Con el mouse

| Acción | Cómo |
| --- | --- |
| Renombrar una pestaña o un panel | Doble clic |
| Cerrar una pestaña | Clic con la rueda |
| Nueva terminal | Doble clic en el espacio vacío de la barra lateral |
| Elegir shell o carpeta para la terminal nueva | Clic derecho en **Nueva terminal** |
| Copiar o pegar | Clic derecho sobre la terminal |
| Dividir | Arrastrar una pestaña sobre la terminal |
| Maximizar la ventana | Doble clic en la franja de arriba |

## Lo que toma Beauty Shell

<kbd>Ctrl+W</kbd> y <kbd>Ctrl+F</kbd> los usa Beauty Shell, así que no le llegan al programa que corre en la terminal. En bash, por ejemplo, <kbd>Ctrl+W</kbd> borra la palabra anterior y <kbd>Ctrl+F</kbd> avanza un carácter: ahí conviene usar <kbd>Alt+Retroceso</kbd> y <kbd>→</kbd>.

Los atajos de la app se resuelven antes de que la terminal vea la tecla. Los demás llegan al programa tal cual.
